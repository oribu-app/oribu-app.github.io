Thanks for your interest in contributing to the Oribu website!

# Contributions

Pull requests are welcome!

## Prerequisites

- Basic [Vue 3](https://vuejs.org/) and [VitePress](https://vitepress.dev/) knowledge.
- [pnpm](https://pnpm.io/) as the package manager - other package managers are blocked by the
  `preinstall` script.

### Tools

```bash
cd website
pnpm install
pnpm dev       # local dev server
pnpm lint      # eslint + markdownlint + stylelint
pnpm build     # production build
```

## Commit messages

This project follows [Conventional Commits](https://www.conventionalcommits.org/en/v1.0.0/).

## Pull requests

Keep PRs focused - one logical change per PR makes review (and revert, if needed) much easier.
